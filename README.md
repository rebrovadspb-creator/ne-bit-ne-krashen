# Не бит, не крашен

Игра про перекупа для Игр ВКонтакте. Игрок осматривает машину из объявления, находит дефекты и улики, раскрывает схемы продавца, торгуется и покупает. Чистый HTML, CSS и JS без фреймворков, ES-модули без сборщика.

**Статус: этап B (MVP к модерации) собран, идёт ручная проверка. Не проверено внутри настоящего ВК и на телефоне.** Разбор исходной игры и план этапов: [docs/PLAN.md](docs/PLAN.md).

## Запуск

Игре нужен сервер (данные грузятся из JSON, из `file://` браузер их не отдаёт):

```bash
npm start          # http://localhost:8000  (сервер без кэша)
npm test           # 89 тестов на node --test
```

Для плейтеста по ссылке подойдёт любой статический хостинг (GitHub Pages): положить папку как есть.

## Параметры адреса для проверки

| Параметр | Что делает |
|---|---|
| `?reset=1` | сбросить сохранение (деньги, репутацию, обучение) |
| `?skiptutorial=1` | пропустить обучение |
| `?seed=11` | воспроизводимое объявление (сид + номер объявления) |
| `?debug=1` | открыть `window.__nbnk` (данные и текущее объявление) |

Примеры сидов (после `?reset=1&skiptutorial=1`): `11` бывшее такси, `4` скрытое ДТП, `6` утопленник, `84` залог у банка, `12` розыск, `2` перекуп, `14` семья.

## Как устроена игра сейчас (этап A)

Объявление → осмотр (3 минуты) → торг → итог покупки → следующее объявление.

- **Осмотр:** вид «Кузов» и «Салон», 12 зон машины (у «Зубила» нет зоны выхлопа), три документа: ПТС, сервисная книжка, одометр. Каждая строка документа проверяется тапом. Подсказки «Палыч подскажет» (2 на осмотр), Пробейка за жетон (1 в день).
- **Схемы:** скрученный пробег, бывшее такси, скрытое ДТП, утопленник (ловушка). Раскрываются по двум уликам (вспышка и карточка), карту схемы продавец принимает всегда.
- **Торг:** продавец просит 1,05 × V0, каждая находка — карта, терпение продавца, блеф. Пять типов продавцов, салон «Честный авто» с 10 уровня репутации.
- **Итог покупки:** найдено, пропущено, что показала бы Пробейка, скидка к объявлению, репутация.
- **Деньги и репутация** сохраняются в `localStorage`.

## Арт

Финальный арт дизайнера подключён. Сборка: `python3 tools/prepare-art.py --zips ПАПКА --pasted ПАПКА` (вырезает серый фон у машин, режет листы иконок и персонажей, ужимает фоны в WebP; исходники лежат вне репозитория, в `assets/` только готовое).

- `assets/cars/<модель>_main.webp` (вид 3/4 для осмотра), `_side.webp` (профиль для списков), `_rare_*` (редкая версия). У «Солярки» профиля нет, в списках используется основной вид.
- Предположение: R1 → «Копейка», R2 → «Зубило», R3 → «Солярка», R4 → «Логарифм» (подтверждено заказчиком). Если понадобится поменять, в `tools/prepare-art.py` словарь `rare` и пересобрать.
- Зоны осмотра заново проставлены по каждой модели в `data/models.json` (`x`, `y` центр, `w`, `h`, % картинки); у редких версий те же зоны, потому что поза совпадает.
- `assets/bg/` фоны: двор (осмотр), рынок (объявление), доска (лента), мастерская (гараж), ряд гаражей (меню), салоны `interior_soviet` и `interior_foreign`, Палыч у гаража (знакомство).
- `assets/chars/`: продавцы по 3 настроения (`<id>_neutral|ok|no`), покупатели `buyer1-8`, Палыч `pal_*`.
- `assets/ui/`: 64 иконки. Используются: навигация, деньги, репутация, реклама, звук, значки всех 28 дефектов (торг, итог, гараж, ремонт), сегменты в ленте, подсказка и Пробейка. Не использованы: подарок, колокол, трофей, приглашение, музыка и несколько мелких.
- `assets/chars/buyer1-8` аватары покупателей в предложениях о продаже.
- Старый серый плейсхолдер и фон гаража удалены.

## Как устроена игра (этап B)

Обучение с Палычем → лента → объявление → осмотр → торг → гараж (ремонт, продажа) → сделка.

- **Лента:** 5 объявлений в сутки (новые в 00:00 по Москве) и закрытая карточка из следующего сегмента. Раз в сутки обновить за рекламу. Комбинация модель+продавец+схема+дефекты не повторяется 30 дней, редкая машина гарантирована раз в 5 дней.
- **Осмотры:** 3 в день, +1 каждые 4 часа, до +2 в сутки за рекламу.
- **Гараж:** 1 место, второе при капитале 400 000. Ремонт параллельный, таймеры 15 мин / 45 мин / 2 ч (таблица дефектов 1/3/8 ч × `repair.timeScale` 0,25 в `data/config.json`) считаются от меток времени (идут и при закрытой игре), ускорение на 1 час за рекламу до 3 раз в сутки.
- **Продажа:** «Быстро» −5% через 1 ч, «Рынок» через 4 ч, «Дорого» +7% через 10 ч (в 40% случаев предложений нет). До трёх предложений ±4%, живут 24 часа. С отчётом Пробейки цена выше (множитель 1,20 против 1,10). Ловушку берёт только скупщик за 62%.
- **Подработка у Палыча:** гараж пуст и денег меньше 120 000 → +30 000 раз в сутки.
- **Реклама:** по кнопке игрока (осмотры, подсказки, жетон Пробейки, возврат продавца, ускорение ремонта, обновление ленты) и межстраничная после сделки не чаще раза в 3 минуты, не в обучении и не в первой сессии. Вне ВК вместо рекламы тестовая заглушка.
- **Сохранение:** в `localStorage` и в облако ВК (сжатое, кусками до 3500 символов, запись не чаще раза в 30 секунд). В сохранении лежат только сиды объявлений и метки времени.
- **Шеринг:** карточка сделки «Взял за 115, продал за 190» уходит в историю ВК; вне ВК скачивается как PNG.

Дополнительные параметры адреса: `?money=N` (стартовые деньги для проверки).

## Что осталось и что не проверено

- Не проверено в настоящем ВК и на телефоне; в песочнице ВК не запускался.
- Параметры `VKWebAppShowNativeAds`, `VKWebAppShare`, `VKWebAppAllowNotifications` не сверены с документацией (страницы были недоступны), проверить перед модерацией. См. шапку `js/vk.js`.
- Новый сегмент и слот открываются сразу, но новые машины видны в ленте только со следующих суток.
- Сегменты 3 и 4, улучшения гаража, легендарные машины, 60 шаблонов текстов (пока по 6 на продавца), финальный арт (все модели на сером силуэте, различаются оттенком).
- Экономика: в симуляции дней до 350 000 медиана 36/16/14 (новичок/средний/про) против целей 21/7/4. Причина: цикл купить→починить→продать занимает около двух суток. Нужно решение по темпу (см. docs/PLAN.md).

| Требование | Статус |

| Главное меню | есть (вкладка «Меню») |
| Обучение | есть (Палыч, 10 шагов) |

| Безопасные зоны 360×800 (верх 56, право-верх 100×56, низ 34) | соблюдены в вёрстке |
| Облачное сохранение, лимит 4096 байт на ключ и 1000 вызовов в час | учтено (тест на размер) |
